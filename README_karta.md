# ГИДРОФРАКТАЛ — вкладка «Карта»

Вкладка «Карта» нужна для просмотра спутниковой подложки и ЦМР:
перетаскивайте карту, меняйте масштаб колесом или кнопками 🔍+/🔍−,
включайте мини-карту. В строке «Курсор на карте» видны координаты под мышью;
поля «Найти по координатам» и кнопка «🔎 Перейти» центрируют карту на нужной
точке. Галочка «Рельеф» включает полупрозрачную отмывку рельефа Esri/USGS.
Никаких расчётов и инструментов выделения здесь нет.

## Просмотр ЦМР внутри сайта

В ленте «Подложка и вид» есть поле **«ЦМР (GeoTIFF)»**, кнопки
**«🏔 Показать ЦМР»** и **«✕ Убрать»**. Выберите GeoTIFF с высотами — он
сразу отобразится на карте (или нажмите кнопку). Если в файле есть геотеги,
слой привязывается к координатам; иначе показывается в текущем виде карты.
После загрузки по ЦМР можно **передвигаться перетаскиванием мыши** и
масштабировать колесом, а в строке ЦМР показывается высота под курсором.
Большие файлы читаются блоками, для отображения берётся уменьшенный уровень
GeoTIFF (overview), поэтому память браузера не переполняется.
ЦМР для просмотра можно скачать на [USGS EarthExplorer](https://earthexplorer.usgs.gov/).

Все расчёты выполняются во вкладке **«Фотоснимок»**.

## Работа с TIFF и NDWI

ЦМР-модели (DEM) можно скачать на [USGS EarthExplorer](https://earthexplorer.usgs.gov/) —
ссылка на него есть и в ленте «TIFF и NDWI». Для NDWI в TIFF должны быть
зелёный и NIR-каналы; файл с одними высотами сам по себе NDWI не даёт.
Большие TIFF читаются потоком и по уменьшенной сетке: проверено на BigTIFF
объёмом 3,2 ГБ с одним страйпом на 3,2 ГБ. Поддерживаются BigTIFF, LZW,
Deflate, PackBits и несжатые данные. geotiff.js используется только для
JPEG-сжатых TIFF.

1. Откройте вкладку «Фотоснимок» → ленту **«TIFF и NDWI»**.
2. Нажмите «TIFF с водой» и выберите:
   - один многоканальный TIFF, в котором есть зелёный и ближний инфракрасный
     каналы (номера каналов задаются полями «Зелёный канал» и «NIR-канал»), либо
   - два TIFF с одним каналом каждый: первый — зелёный, второй — NIR.
3. Задайте **диапазон NDWI** двумя ползунками: нижняя граница по умолчанию −0,25,
   верхняя — +1,00. К воде относятся значения между ними.
4. Нажмите **«💧 Выделить воду по NDWI»**: приложение построит снимок и маску
   воды, но не будет считать D автоматически.
5. Маску и створ можно поправить вручную, затем нажать **«📐 Рассчитать D»**.
   Для выделения реки по цвету створа есть отдельная кнопка
   **«🌊 Выделить реку (по створу)»** — сначала поставьте створ кликом по руслу.

Если у GeoTIFF есть геотеги, в ленте «Ориентация, обрезка, сетка и масштаб»
появится поиск по координатам: введите Y и X в системе координат файла
(градусы или метры) и нажмите «🔎 Найти в TIFF» — снимок приблизится к точке,
а на ней будет поставлена метка.

NDWI считается как `(G − NIR)/(G + NIR)`. К воде относятся пиксели, попавшие
в заданный диапазон (по умолчанию от −0,25 до +1,00).
Обычная карта высот сама по себе NDWI не даёт — нужны именно спектральные каналы.

## Источники подложки

| Слой | Источник | Лицензия |
|---|---|---|
| Sentinel-2 L2A | Planetary Computer (STAC + TiTiler) | Открытые данные Copernicus |

Атрибуция показывается внизу карты.
