# Запуск программы «Фрактальная размерность реки» — пошагово

## Шаг 0. Что понадобится
- Компьютер с Windows / macOS / Linux
- Python 3.9+ (обычно 3.10–3.13)
- Файл `river_fractal.py` (лежит рядом с этим README)
- Спутниковый снимок реки: `.jpg`, `.png` или `.tif`

---

## Шаг 1. Проверьте, установлен ли Python

**Windows:**
1. Откройте «Пуск» → введите `cmd` → откройте «Командная строка»
2. Выполните:
   ```
   python --version
   ```
   Если видите `Python 3.xx.x` — Python есть, переходите к шагу 2.
   Если «python не является внутренней или внешней командой» — установите с https://www.python.org/downloads/ и **при установке обязательно поставьте галочку «Add Python to PATH»**.

**macOS / Linux:**
```bash
python3 --version
```
Если команды нет:
- macOS: `brew install python` (или с сайта python.org)
- Linux (Ubuntu/Debian): `sudo apt install python3 python3-pip python3-tk`

---

## Шаг 2. Перейдите в папку с программой

**Windows:**
```
cd C:\путь\к\папке\
```
Пример: `cd C:\Users\Иван\Desktop\river`

**macOS / Linux:**
```bash
cd ~/путь/к/папке
```
Пример: `cd ~/Desktop/river`

Проверить, что файл на месте:
- Windows: `dir river_fractal.py`
- macOS / Linux: `ls river_fractal.py`

---

## Шаг 3. Установите библиотеки (один раз)

**Windows:**
```
pip install numpy pillow opencv-python scikit-image matplotlib reportlab
```
Если `pip` не сработал:
```
python -m pip install numpy pillow opencv-python scikit-image matplotlib reportlab
```

**macOS / Linux:**
```bash
python3 -m pip install numpy pillow opencv-python scikit-image matplotlib reportlab
```

Важно:
- `tkinter` отдельно ставить не нужно на Windows и macOS (встроен в Python).
- На Linux нужен пакет: `sudo apt install python3-tk`
- `matplotlib` и `scikit-image` не строго обязательны: без `matplotlib` не будет графика (и PDF-отчёт сохранится как TXT), без `scikit-image` вместо «скелета» будет режим «граница воды».
- `reportlab` нужен для PDF-отчёта; если его нет, отчёт сохранится текстовым файлом (TXT) с теми же данными.

---

## Шаг 4. Запустите программу

**Windows:**
```
python river_fractal.py
```
**macOS / Linux:**
```bash
python3 river_fractal.py
```
Откроется окно «Фрактальная размерность реки по спутниковому снимку».

---

## Шаг 5. Как работать с программой

1. **«📂 Загрузить снимок»** — выберите файл со спутниковым снимком реки.
2. **Кликните мышью по реке** на изображении (например, по тёмно-синему руслу).
   Внизу появится строка: координаты и RGB выбранной точки.
3. Выберите **«Способ выделения»**:
   - «По цвету точки (HSV)» — лучший вариант для цветных снимков;
   - «Тёмная вода (яркость)» — если река просто темнее берегов (серый снимок);
   - «Комбинация признаков» — если один из критериев выделяет плохо.
4. Подвигайте **«Допуск по цвету»** (начните с 60–80) и нажмите **«🌊 Выделить реку»**.
   Река подсветится зелёным. Если выделилось слишком много/мало — измените допуск и повторите.
5. Если на снимке несколько тёмных объектов, оставьте галочку
   **«Только крупнейшая область воды»** (иначе в расчёт попадёт и тень от леса, и дороги).
6. (Необязательно) Переверните снимок кнопками **«⟲ 90°»** / **«⟳ 90°»** / **«180°»** / **«⇋»** / **«⇵»**.
7. **ВАЖНО — оставьте выделенной только часть реки ВЫШЕ створа.**
   Точка, в которую вы кликнули (точка расхода) — это створ, относительно которого
   считается D (и в дальнейшем расход). Всё, что ниже по течению от створа,
   в расчёте участвовать не должно: выберите инструмент **«🧹 Ластик»** и сотрите
   им ВСЮ зелёную область ниже створа (ведите мышью с зажатой левой кнопкой).
   Под холстом и в подсказке ластика об этом напоминает красная надпись.
8. Выберите **«Объект расчёта»**:
   - «Скелет (центр русла)» — самый правильный вариант;
   - «Граница воды (контур)» — если scikit-image не установлен;
   - «Заполненная маска» — не рекомендуется, размерность завышается к 2.
9. Нажмите **«📐 Рассчитать D»** — справа появится:
   - фрактальная размерность `D = 1 + h/2` (метод Кантора, квадраты) с ошибкой и R²;
   - таблица (n, ε, N);
   - график log N(ε) vs log(1/ε) (прямая должна быть визуально прямолинейной, R² → 1).
10. Кнопки **«💾 Сохранить маску (PNG)»** и **«📄 Сохранить отчёт (PDF)»** сохраняют результаты.
    **PDF-отчёт** — «Отчёт о значениях фрактальной размерности, среднего многолетнего
    расхода воды, коэффициента вариации, коэффициента асимметрии и кривой обеспеченности
    для выбранного створа реки» (A4, односторонняя печать): параметры расчёта и результаты
    (таблицы 1–2, R² и r — до 10 знаков после запятой), рисунок 1 — график log N(ε),
    таблица 3 — полные измерения (60 строк, заголовок повторяется на каждой странице),
    рисунок 2 — снимок со створом, рисунок 3 — ОТДЕЛЬНАЯ страница с маской реки
    (чёрный — вода, белый — фон), **таблица 4 — статистические характеристики стока
    (Q<sub>ср</sub>, м³/с, C_v и C_s — нижними индексами; 5 колонок: характеристика,
    обозначение, значение, относительная погрешность, % и относительная погрешность)**,
    **рисунок 4 — «Теоретическая кривая обеспеченности (Пирсона III типа)»: бланк-
    клетчатка на АЛЬБОМНОЙ странице A4** (ось P — обеспеченность 0,1…99,9 % на
    вероятностной шкале, ось Q — расход, м³/с; справа — шкала модульных
    коэффициентов K_P), **таблица 5** (P, K_P, Q_P) под бланком и **формулы с
    пояснениями**: Q_P = K_P·Q_ср, K_P = Φ_P·C_v + 1, Φ_P по Фостеру–Рыбкину.
    **Структура PDF**: титульный лист → **I** исходные данные → **II** результаты D → **III** полная таблица
    измерений → **IV** снимок и маска → **V** статистические характеристики стока →
    **VI** теоретическая кривая обеспеченности (альбомный лист, почти вся страница,
    шкала K_P слева, промежуточные деления) → **VII** таблица 5 (P, K_P, Q_P) и
    «Порядок вычисления» основным текстом с **нумерованными формулами** (1)–(8).
    Оглавления нет — разделы нумеруются римскими цифрами прямо в заголовках.
    **Каждая глава начинается с новой страницы.**
    **Формулы выровнены по центру полосы, номер в скобках — справа от формулы
    на той же строке.** Подписи таблиц — **по правому краю**.
    Корень в формулах погрешностей записан скобками со степенью 1/2 — (…)^1/2,
    подпункты начинаются с маркера «•».
    После таблицы 4 основным текстом идут **формулы абсолютных и относительных
    погрешностей** (ε_Q, ε_Cv, ε_Cs и их процентные варианты).
    Примечания и пояснения выровнены по ширине; под таблицами 3 и 4 — «Пояснение:».
    В нижней части таблицы 3 — серые пояснения (n, ε, N(ε), log₁₀). Все таблицы
    выровнены по центру; в формулах и подписях — настоящие нижние индексы (log₁₀);
    десятичные числа везде с запятой (и на графиках).

**Природная цветовая гамма интерфейса** (по образцу): олива `#9CA75A`,
беж `#DACAB0`, крем `#F3EBE0`, коричневый `#8B6431`, бордо `#733933`.
Цветами охвачены **все** элементы: кнопки, поля ввода, ползунки (оливковый
бегунок на бежевом жёлобе), флажки, выпадающие списки, скроллбары, текстовое
поле отчёта, полоса состояния и графики (оливковые точки, бордовая линия,
кремовый фон). Классические `tk.Scale`, которые не перекрашиваются, заменены
на `ttk.Scale` с отдельным полем для числа.

**Инструменты правки маски** (вторая панель): «🖱 Точка расхода (створ)»,
«➕ Доп. точка цвета», «✋ Двигать», «🧹 Ластик», «🖌 Кисть».

- **Доп. точка цвета** — не створ: клик по участку воды другого оттенка
  (мутный приток, тень на воде) добавляет этот цвет в эталоны. Маска
  **пересобирается сразу после клика** — нажимать «🌊 Выделить реку»
  не нужно. Эталон берётся как медиана цвета по кружку вокруг клика
  (радиус = размер кисти), поэтому шум отдельного пикселя не мешает.
  Точки помечаются жёлтыми кружками «2», «3», …; повторный клик по
  точке убирает её.
- **Отмена и повтор** — кнопки «↶ Назад» / «↷ Вперёд» (Ctrl+Z / Ctrl+Y).
  Отменяется целый штрих ластика или кисти и добавление/удаление
  доп. точки — до 50 последних действий. Новое действие очищает
  историю «вперёд».

**Перед расчётом** «📐 Рассчитать D» спрашивает подтверждение: показывает число
пикселей воды, признак «маска правилась вручную/автоматически», объект расчёта
и число делений сетки — чтобы случайно не посчитать не то.

**Поля «Характеристики стока»** в правой панели (Qср, м³/с, Cv, Cs): если их
заполнить, кривая обеспеченности строится по вашим данным; если оставить пустыми —
по фрактальной размерности D (калибровочная связь, ориентировочно).
    Оформление: Times New Roman (в папке `fonts/` — Tinos, метрический аналог Times New Roman),
    поля левое 3 см / правое 1,5 см / верхнее и нижнее по 2 см, основной текст 14 pt,
    таблицы 12 pt, примечания 10 pt, межстрочный интервал 1,5, абзацный отступ 1,25 см,
    выравнивание по ширине, страницы пронумерованы, рисунки и таблицы подписаны
    («Рисунок 1 — …», «Таблица 1 — …»).
    **Маска сохраняется как ЧЁРНАЯ река на БЕЛОМ фоне** (маска-подложка для ГИС).
    В метаданные PNG записываются: размер (px), разрешение (300 dpi), масштаб
    (из поля «Масштаб, м/пиксель», если вы его заполнили), источник снимка,
    число пикселей воды, точка расхода и дата.

**Масштабирование и перемещение снимка:**
- **колесо мыши** над холстом — увеличить/уменьшить (зум к курсору, до 12×);
- кнопки **«🔍−»** / **«🔍+»** — то же к центру; **«⛶ Всё»** — вернуть масштаб 100% (вся картинка);
- инструмент **«✋ Двигать»** или **средняя кнопка мыши** (тащить) — панорамирование;
- **«🗺 Карта»** — открыть мини-окно «🗺 Карта просмотра»: вся картинка целиком
  с красной рамкой текущего вида; клик или перетаскивание по мини-карте — перейти к месту;
- выпадающий список **«Вид:»** — «Снимок + маска» / «Только снимок» / «Только маска»
  (белая река на чёрном фоне, чтобы проверить выделение).

**«🗑 Закрыть снимок»** (в верхней панели, рядом с «📂 Загрузить снимок») — прекращает работу
с текущим снимком: открывается предупреждение «Вы уверены, что хотите прекратить работу
с данным спутниковым снимком?». Если подтвердить — снимок, маска, точки и результаты
удаляются; если отказаться — ничего не меняется.

## Шаг 6. Типичные проблемы и решения

| Проблема | Решение |
|---|---|
| `pip` не найден | используйте `python -m pip ...` (Windows) или `python3 -m pip ...` |
| «Не хватает библиотеки: cv2» | `pip install opencv-python` |
| Окно не открылось / `_tkinter` error на Linux | `sudo apt install python3-tk` |
| Снимок открылся чёрным (16-битный TIFF) | такого в программе быть не должно, 16 бит обрабатывается автоматически; если всё же так — сохраните снимок как 8-битный PNG в редакторе |
| Выделилась не вся река, а «кусочки» | увеличьте допуск или смените способ выделения |
| Выделилось слишком много (тени, дороги) | уменьшите допуск, оставьте «Только крупнейшая область воды» |
| D близка к 2 | вы считаете по «Заполненной маске» — переключите на «Скелет» или «Граница» |
| Картинка слишком маленькая в окне | это не мешает клику — координаты пересчитываются автоматически |

## Важно: точка расхода и «только выше створа»

Клик по реке ставит **точку расхода (створ, красный маркер «1»)**:
относительно неё считается фрактальная размерность — и, в дальнейшем, расход.
Всё, что ниже по течению от створа, в расчёт попадать не должно. Автоматической
обрезки в программе нет: выделите реку, затем инструментом **«🧹 Ластик»** сотрите
ВСЮ зелёную область ниже створа, оставив только часть реки ВЫШЕ створа.
Если стёрли лишнего — **«🖌 Кисть»** восстановит, либо нажмите «🌊 Выделить реку»
и выделите заново. После любой правки маски снова нажмите «📐 Рассчитать D».

## Две панели инструментов (что нового)

**Первая строка** — загрузка снимка и параметры выделения (как раньше).
**Вторая строка** — инструменты мыши и объект расчёта:

| Элемент | Что делает |
|---|---|
| Инструмент → «🖱 Точка расхода (створ)» | клик по реке задаёт эталон цвета и створ (точка 1) |
| «⟲ 90°» / «⟳ 90°» / «180°» / «⇋» / «⇵» | поворот и отражение снимка (маска и точки едут вместе) |
| Максимальное число делений сетки | верхний предел n в сетке n×n метода Кантора (квадраты) (по умолчанию 60) |
| «Вид:» | показать снимок с маской / только снимок / только маску |
| «🔍−» / «🔍+» / «⛶ Всё» | масштаб снимка (до 12×) / вернуть 100% |
| «🗺 Карта» | мини-окно с красной рамкой вида; клик — перейти к месту |
| «✋ Двигать» | панорамирование снимка (или средняя кнопка мыши) |
| Масштаб, м/пиксель | попадает в метаданные PNG маски (размер, 300 dpi тоже записываются) |
| Инструмент → «🧹 Ластик» | стирает ошибочно выделенные области маски (вести с зажатой ЛКМ) |
| Инструмент → «🖌 Кисть» | дорисовывает области, которые программа не выделила |
| Размер ластика/кисти | радиус штриха в пикселях исходного снимка (2–80) |
| Объект расчёта | Скелет / Граница / Заполненная маска |

Важно: любое ручное исправление маски обнуляет готовый расчёт — после правок снова нажмите **«📐 Рассчитать D»**.

## Всплывающие подсказки

Наведите курсор на любой параметр (способ выделения, допуск, флажки, объект расчёта, кнопки) — через полсекунды появится подсказка: что это, как менять и как это влияет на D.
