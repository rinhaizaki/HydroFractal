# ГИДРОФРАКТАЛ — режим карты

Программа открывает спутниковую карту, вы кликаете по реке — и она
**сама** строит водосбор по рельефу. Никакой ручной обводки, никаких
файлов ЦМР скачивать не нужно.

---

## Запуск

```
pip install numpy pillow matplotlib reportlab scipy
python map_app.py
```

Интернет нужен — карта и рельеф берутся из сети.

---

## Как работать

1. **Перетаскивайте карту** левой кнопкой (или средней — тоже работает).
2. **Колесо мыши** — масштаб. Центр под курсором остаётся на месте.
3. **Режим «🎯 Выбрать створ» включён по умолчанию**: кликните по реке —
   появится красный маркер «1». Это створ.
4. **«🌊 Водосбор → фото»** — программа скачает рельеф участка, заполнит
   впадины, посчитает направления стока и найдёт **всю речную сеть**, с которой
   вода приходит к створу. По этому водосбору обрезается спутниковый снимок,
   открывается вкладка «Фотоснимок», и речная сеть становится маской снимка.
5. Во вкладке **«Фотоснимок»** D и все характеристики считаются уже по
   подготовленному снимку; маску и створ можно поправить и пересчитать.
6. **«📐 Рассчитать D»** на карте — только быстрый предварительный просмотр.
7. **«💾 Отчёт PDF»** (в фото-вкладке) — отчёт со снимком водосбора,
   морфометрией и результатом.
8. **«🌐 EarthExplorer»** открывает архив USGS EarthExplorer — источник NASADEM/SRTM.
   Координаты центра копируются в буфер. Скачивание исходных файлов требует
   собственной учётной записи USGS; приложение получает ту же ЦМР из открытого
   каталога Planetary Computer без регистрации.

## Источники данных

| Слой | Источник | Лицензия |
|---|---|---|
| Спутниковый снимок | Sentinel-2 L2A через Planetary Computer STAC + TiTiler | Открытые данные Copernicus, нужна атрибуция |
| Резервный снимок | Esri World Imagery (Maxar, Earthstar) | Бесплатно для некоммерческого использования, нужна атрибуция |
| Высоты рельефа | NASADEM/SRTM (архив USGS EarthExplorer) через Planetary Computer; запасной — Copernicus DEM GLO-30, затем Terrarium | Открытые данные USGS/NASA, ~30 м |

Атрибуция показана внизу окна карты — это требование лицензий,
не убирайте её.

## Про рельеф: почему не растровая карта

Растровая топокарта — это **нарисованная карта**: изолинии, подписи, отмывка.
Внутри тайла лежат цвета палитры, а не числа высот. Из неё нельзя
получить массив высот, а без него водосбор не построить.

Поэтому высоты берутся из **NASADEM/SRTM** — данные USGS EarthExplorer,
опубликованные через Planetary Computer. Если сервис возвращает ошибку,
приложение переключается на **Copernicus DEM GLO-30**, а затем на обычные
terrarium-тайлы с настоящими высотами: одноканальный DEM кодируется в PNG с lin. шкалой
−1000…4000 м. Программа декодирует метры из красной компоненты:
`h = −1000 + R/255 · 5000`.

Sentinel-2 даёт настоящие спектральные каналы: NDWI считается как
`(B03 − B08) / (B03 + B08)`, по нему выделяются водные объекты, а расчёт
водосбора идёт по настоящим высотам ЦМР.

**Что именно покрывают квадраты.** При расчёте фрактальной размерности реки
методом Кантора учитываются только клетки, через которые проходит русло
(и притоки, если они входят в маску). Площадь водосбора сама по себе не
входит в счёт: если считать все клетки внутри водосбора, получится D ≈ 2 —
это размерность площади, а не извилистости реки.

## Ограничение по разрешению — важно

Тайлы рельефа — это Copernicus DEM GLO-30 **~30 м**. Клетка ~30 м означает:

- **Крупные и средние реки** (Волга, Кубань, горные реки) — работает хорошо
- **Ручьи шириной 3–5 м** — не видны в такой сетке; водосбор построится,
  но линия русла будет приблизительной

Программа **специально не поднимает зум рельефа выше z12**. Причина:
на z13+ тайлы рельефа интерполируются, деталей не прибавляется, а
алгоритм D8 начинает цепляться за шум интерполяции — и поток
рассыпается на тысячи бессмысленных лоскутков. Лучше честно работать
на родном разрешении данных.

## Типичные проблемы

**«Створ попал на водораздел»** — кликните точнее по видимому руслу.
На склоне своего водосбора нет: вода с него уходит в другую сторону.

**Водосбор подозрительно маленький** — вы кликнули по ручью, а не по
главной реке. Кликните ниже по течению: чем ниже створ, тем больше
водосбор.

**Карта не загружается** — нет интернета или провайдер блокирует
`arcgisonline.com`. Попробуйте переключить слой на резервный Esri / Google Satellite.

**Расчёт идёт долго** — на первом запуске качается 20 тайлов рельефа.
Дальше они берутся из кэша, и всё считается за 1–2 секунды.
