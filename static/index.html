КАРТА И ВОДОСБОР

1. Перетаскивайте карту ЛКМ, меняйте масштаб колесом мыши.
2. Кликните по руслу реки — появится красный маркер створа.
3. «🌊 Водосбор → фото» — по ЦМР находится вся речная сеть и водосбор
   до створа; спутниковый снимок обрезается по водосбору и открывается
   во вкладке «Фотоснимок». Маска сети и створ переносятся туда автоматически,
   D считается уже по этому снимку.
4. Во вкладке «Фотоснимок» маску и створ можно поправить вручную и нажать
   «📐 Рассчитать D» для пересчёта; оттуда же сохраняется PDF-отчёт.
5. «📐 Рассчитать D» на карте — быстрый предварительный расчёт без перехода в фото.
6. Поле «Вид» показывает снимок с водосбором, только снимок или только маску.
7. Метки ставятся кликом или по координатам; список ниже позволяет их
   переименовывать и удалять. Кнопка «Рисовать» добавляет линии поверх карты.
