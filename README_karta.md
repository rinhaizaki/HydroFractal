# ГИДРОФРАКТАЛ — режим карты

Программа открывает спутниковую карту, вы кликаете по реке — и она
**сама** строит водосбор по рельефу. Никакой ручной обводки, никаких
файлов ЦМР скачивать не нужно.

---

## Запуск

```
pip install numpy pillow matplotlib reportlab scipy
python map_app.py
```

Интернет нужен — карта и рельеф берутся из сети.

---

## Как работать

1. **Перетаскивайте карту** левой кнопкой (или средней — тоже работает).
2. **Колесо мыши** — масштаб. Центр под курсором остаётся на месте.
3. **Кликните по реке** — появится красный маркер «1». Это створ.
4. **«🌊 Построить водосбор»** — программа скачает рельеф участка,
   заполнит впадины, посчитает направления стока и найдёт все клетки,
   с которых вода приходит к створу.
5. **«📐 Рассчитать D»** — фрактальная размерность по линии главного
   русла методом Кантора (квадраты).
6. **«💾 Отчёт PDF»** — отчёт с картой, морфометрией и результатом.

## Источники данных

| Слой | Источник | Лицензия |
|---|---|---|
| Спутниковый снимок | Esri World Imagery (Maxar, Earthstar) | Бесплатно для некоммерческого использования, нужна атрибуция |
| Топографическая карта | OpenTopoMap | CC-BY-SA, данные © OpenStreetMap |
| Высоты рельефа | AWS Terrain Tiles (Mapzen) | Открытые данные, SRTM/ETOPO |

Атрибуция показана внизу окна карты — это требование лицензий,
не убирайте её.

## Про рельеф: почему не OpenTopoMap

OpenTopoMap — это **нарисованная карта**: изолинии, подписи, отмывка.
Внутри тайла лежат цвета палитры, а не числа высот. Из неё нельзя
получить массив высот, а без него водосбор не построить.

Поэтому высоты берутся из **AWS Terrain Tiles** — это открытые данные
SRTM 30 м, закодированные в цвете (кодировка terrarium). Программа их
декодирует в метры: `h = R*256 + G + B/256 − 32768`.

OpenTopoMap подключён как альтернативный слой — он полезен, чтобы
**видеть** рельеф глазами (изолинии, высотные отметки), но расчёт
идёт по настоящим высотам.

---

## Ограничение по разрешению — важно

Тайлы рельефа — это SRTM **30 м**. Клетка ~30 м означает:

- **Крупные и средние реки** (Волга, Кубань, горные реки) — работает хорошо
- **Ручьи шириной 3–5 м** — не видны в такой сетке; водосбор построится,
  но линия русла будет приблизительной

Программа **специально не поднимает зум рельефа выше z12**. Причина:
на z13+ тайлы рельефа интерполируются, деталей не прибавляется, а
алгоритм D8 начинает цепляться за шум интерполяции — и поток
рассыпается на тысячи бессмысленных лоскутков. Лучше честно работать
на родном разрешении данных.

## Что внутри

| Файл | Назначение |
|---|---|
| `map_app.py` | Окно карты (запускать этот файл) |
| `map_core.py` | Тайлы, геометрия, гидрология, отрисовка |
| `river_fractal.py` | Расчёт D методом Кантора и характеристики стока |
| `test_map.py` | 13 проверок картографического режима |
| `fonts/` | Шрифты для PDF (Tinos) |

Кэш тайлов складывается в папку `tile_cache/` рядом с программой.
Её можно удалить в любой момент — скачается заново.

## Типичные проблемы

**«Створ попал на водораздел»** — кликните точнее по видимому руслу.
На склоне своего водосбора нет: вода с него уходит в другую сторону.

**Водосбор подозрительно маленький** — вы кликнули по ручью, а не по
главной реке. Кликните ниже по течению: чем ниже створ, тем больше
водосбор.

**Карта не загружается** — нет интернета или провайдер блокирует
`arcgisonline.com`. Попробуйте переключить слой на OpenTopoMap.

**Расчёт идёт долго** — на первом запуске качается 20 тайлов рельефа.
Дальше они берутся из кэша, и всё считается за 1–2 секунды.
